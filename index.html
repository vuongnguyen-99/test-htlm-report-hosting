This page is served directly from a GitHub repository via GitHub Pages — no build step, no server, just a static index.html at the top level of the publishing source.

01

Entry file

GitHub Pages looks for index.html, index.md, or README.md at the top level of the publishing source.

02

Publishing source

Configured per-repo under Settings → Pages — either a branch/folder or a GitHub Actions workflow artifact.

03

Build & deploy

Every push to the publishing source triggers a GitHub Actions run that builds and deploys the site automatically.
